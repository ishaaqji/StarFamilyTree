# Star Shajara

Star Shajara — Universal Family Tree Platform.

## Current status

**Architectural Scaffold Only — NOT v1.0.0 GA**

This repository currently contains the foundational TypeScript/Express scaffold and an initial PostgreSQL migration pattern. The previously described full GA implementation, 49-migration set, and large validation/test suite are not present in this repository and must not be represented as implemented.

## Scaffold

- Node.js + TypeScript
- Express
- PostgreSQL connection dependency
- Basic health endpoint
- Initial migration pattern
- Environment example
- Git hygiene / secret exclusions
